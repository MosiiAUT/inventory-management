Factory Inventory Management System

A demo full-stack app: a Vue 3 single-page dashboard talks to a Python FastAPI service, which serves mock data loaded from JSON files into memory. There is no database, no authentication and no persistence.

System architecture

Request path runs bottom-up on the right: route handler, filters, response model, data held in memory by mock_data.py.

Data flow: changing a filter

  1. The user picks a value in FilterBar.vue, for example Warehouse = Tokyo.
  2. That writes to a ref in useFilters.js. The refs are declared at module level, so every view shares the same filter state.
  3. The current view has a watch() on the filters it cares about and calls getCurrentFilters().
  4. api.js turns the filters into query params, leaving out any that are all: GET /api/orders?warehouse=Tokyo.
  5. FastAPI runs apply_filters() and filter_by_month() over the in-memory lists with plain list comprehensions.
  6. The result is validated against the response_model and returned as JSON.
  7. The view stores it in a ref. Totals, chart series and tables are computed from it, and currency formatting follows the language (en uses USD, ja uses JPY).

Things worth knowing

Client calls endpoints that don't exist

api.js defines task and purchase-order calls, but main.py has no such routes, so they return 404. App.vue catches the error, and the tasks shown are the mock ones from useAuth.js.

Unrouted view

views/Backlog.vue exists but isn't registered in main.js, so no URL reaches it. Backlog data appears on the Dashboard.

Inconsistent API access

Reports.vue hardcodes http://localhost:8001 and calls axios itself instead of going through api.js, which also hardcodes the base URL.

Demo-only assumptions

Quarters only cover 2025, writes are never saved, CORS accepts any origin, and the logged-in user is hardcoded.
